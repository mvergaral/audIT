# Regeneración del Informe 3.1

El generador utiliza `build/origen.xlsx` e `insumos.json` versionados junto con `referencia-3.0.json`. El origen económico es `c9a6515652c3357ea684bf0bb9338b7c4ec028fd`. La demanda D3 corresponde al corte técnico del 12 de noviembre; los precios, capital e indicadores de contraste proceden de la planilla auditada del 14. `extraer_insumos.py` se usa únicamente si se requiere renovar insumos. Requiere `AUDIT_ORIGIN_REPO` con el repositorio de origen y su historial.

Ejecutar desde este directorio. Usar el Node y los módulos del entorno de artefactos, un Python con openpyxl, Matplotlib, PyMuPDF y lxml, y LuaLaTeX/Latexmk. Enlazar los módulos de Node en este directorio con `ln -s "$RUNTIME_NODE_MODULES" node_modules`. Las rutas de Node, Python y de las dependencias se obtienen del entorno de trabajo.

1. Ejecutar `node build/modelo.mjs`, `python publicar_planilla.py` y `node build/probar_modelo.mjs`. El primer comando genera fórmulas, formatos y gráficos. El segundo conserva las cachés y aplica la protección y validaciones de Excel. El tercero comprueba propagación en una copia en memoria. Los scripts `formato_final.mjs`, `cerrar_modelo.py`, `proteger_salida.py` y `probar_planilla.py` proceden del flujo anterior de Calc. El corte 3.1 se construye con la secuencia anterior.
2. Ejecutar `python verificar_entrega.py --series-only` y luego `python preparar_informe.py`. Para compilar, copiar o enlazar la plantilla oficial en un árbol temporal con su ruta `recursos/Formato-Oferta-audIT` y enlazar el `Informe-3` de las fuentes de mejora en la raíz de ese árbol. Crear `salida` y `luacache` en la plantilla temporal. Desde la plantilla, ejecutar `TEXMFCACHE=luacache TEXMFVAR=luacache latexmk -lualatex -outdir=RUTA_REVISION_LATEX -jobname=INFORME3_AUDIT_COSTOS_VENTA_20261115 RUTA_DOCUMENTO_TEX`. El directorio de salida es `outputs/informe3-mejora/revision/latex`, relativo a `Fuentes/repo`.
3. Ejecutar `AUDIT_TEX_ROOT=RUTA_PLANTILLA_TEMPORAL python verificar_entrega.py`. El verificador guarda las series de PowerPoint y verifica el PDF compilado contra el libro. `--series-only` genera solo las series. Mantener el mismo libro para ambos pasos.
4. Ejecutar `node build/presentacion.mjs` con `AUDIT_SLIDES_SKILL`, `AUDIT_PYTHON` y `RUNTIME_NODE_MODULES`. Mover antes el PPTX y el recibo de validación existentes de la carpeta de trabajo. El validador evita sobrescribirlos. Ejecutar `python exportar_presentacion_pdf.py` para obtener la copia de lectura.
5. Después de revisar los PDF y las pruebas, ejecutar `python empaquetar.py`. Lee el LEEME y el registro de `Entrega-3.1`, verifica los cuatro documentos y actualiza el CSV, manifiesto y ZIP. `Entrega-3.0` se usa solo como referencia de lectura.

Para comprobar el prototipo local, superponer `Fuentes/PaginaAudIT/src` en una copia de trabajo del sitio de origen y ejecutar `npm run build` y `npm test`. El despliegue público anterior sirve para verificar la ruta de navegación.
