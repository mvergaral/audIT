## Validación de Sonar antes de contratar

Ante una compra real se solicitaría SonarQube Server Developer autogestionado, una instancia en Chile, integración GitLab y análisis de C#, Go, JavaScript/TypeScript y Dart/Flutter. La capacidad inicial propuesta de 100.000 LOC no es código medido. Se confirmaría que EUR 215 corresponde a doce meses, que se puede emitir la licencia a Curimón y que sus condiciones permiten la continuidad y transferencia exigidas por Art.84, además de precio aplicable a Chile, renovaciones, ampliaciones, soporte, impuestos y canal. Al existir código se valida el tramo real; las líneas LaTeX de este repositorio no lo dimensionan. El catálogo y las condiciones generales no sustituyen una oferta de ese alcance. Para el Informe 3 se entrega el presupuesto de referencia con supuestos y escenario alternativo; no se requiere contactar al proveedor para cerrar AUD-25.
