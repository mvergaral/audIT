## Requerimiento listo para cotizar Sonar

Solicitar SonarQube Server Developer autogestionado, una instancia en Chile, integración GitLab y análisis de C#, Go, JavaScript/TypeScript y Dart/Flutter. Pedir precios por tramos de LOC que cubran el conteo real, método de medición, anualidad, ampliaciones, soporte, impuestos, canal y ambiente de evaluación. El repositorio de este trabajo contiene informes, no el código aplicativo proyectado: su cantidad de líneas LaTeX no sirve para dimensionar la licencia.
