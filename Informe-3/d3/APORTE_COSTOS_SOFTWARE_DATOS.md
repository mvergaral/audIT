# Insumos D3 para proveedores, adquisiciones y costos del Informe 3

**Alcance:** software, datos y proceso de desarrollo definidos en S4.1, S5 y S6. Este archivo entrega unidades y responsables de validación al equipo que arma el documento económico y la planilla del mandante. Las bases piden proveedores, adquisiciones, curva S, costos y flujo mensual (FEP01, Formulario T-22, p. 69). D3 no fija precios ni modifica las partidas económicas compartidas sin cotizaciones y conciliación con S7/T-15, T-11 y E-26.

**Proveedor clave identificado por diseño:** Microsoft Azure para los servicios administrados y GitLab para la plataforma CI Enterprise. Los demás productos son herramientas del pipeline cuya edición y modalidad de contratación siguen por confirmar. No se presenta una cotización ni se da por contratado ningún proveedor.

**Dependencia para cerrar el Informe 3:** obtener cotizaciones y tarifas, decidir edición/licencia de las herramientas, fijar meses de uso con S7, conciliar la compra cloud con T-11 y cargar una sola vez cada costo en la planilla mensual. La curva S, VAN y TIR se calculan sobre el presupuesto común; este archivo sólo entrega los insumos D3. La valorización de la innovación 2 está separada en `APORTE_ECONOMICO_INNOVACION_2.md`.
