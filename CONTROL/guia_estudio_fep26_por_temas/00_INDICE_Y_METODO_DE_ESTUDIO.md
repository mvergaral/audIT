# Guía de estudio FEP26 por temas

Esta carpeta divide el compendio en archivos Markdown cortos por categoría. Lee el índice para elegir el tema; cada módulo funciona de forma independiente y enlaza con el siguiente paso del estudio.

## Cómo estudiar

1. **Comprende:** lee un archivo y anota las ideas que conectarías con un caso real.
2. **Recupera:** cierra el archivo y explica el tema en voz alta o en una hoja.
3. **Practica:** resuelve ejercicios sin mirar las respuestas.
4. **Corrige:** registra el error concreto y la pista del enunciado que debiste detectar.

En cálculos, escribe siempre `datos → fórmula → reemplazo con unidades → resultado → interpretación`. En casos, responde `concepto → evidencia → decisión → justificación → consecuencia`.

## Relaciones que conviene dominar

- Requisito → alcance → EDT → actividades → cronograma → estimación → costo y precio.
- Atributo de calidad → decisión arquitectónica → infraestructura → métrica o prueba → aceptación contractual.
- Causa → evento de riesgo → efecto → respuesta → riesgo residual y secundario.
- Entregable construido → control de calidad → entregable verificado → validación del alcance → aceptación formal.

## Convenciones de la materia

Algunas lecturas presentan variantes de factores o criterios de estimación. Usa la fórmula y los pesos indicados en el enunciado y declara qué convención estás aplicando. No mezcles Punto Función con Punto de Caso de Uso ni horas de programación con esfuerzo total del ciclo de vida.
