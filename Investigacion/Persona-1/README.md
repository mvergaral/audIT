## 4. Criterio rector

TI-12 es el tema central y Transportes Curimón S.A. es su caso de aplicación. El informe debe convertir cada obligación normativa en una cadena verificable:

> **Norma → obligación → aplicación al Caso 10 → actividad → rol → plazo → evidencia → costo.**

Persona 1 debe rechazar cualquier sección que describa normas sin aterrizarlas al proyecto, que use cifras sin fuente o que contradiga la arquitectura y el modelo económico.
