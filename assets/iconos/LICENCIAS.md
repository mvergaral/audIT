# Íconos de tecnología

- `azure-*.svg`: Azure Architecture Icons V23 de Microsoft (arch-center.azureedge.net). Uso permitido para representar el servicio de Azure correspondiente en diagramas de arquitectura, sin recortar, rotar ni deformar, y con el nombre del servicio cerca del ícono (Azure_Icons_FAQ.pdf).
- `si-*.svg`: Simple Icons 13.21.0 (CC0 1.0), con el color de marca oficial. Las marcas pertenecen a sus dueños y se usan sólo para identificar la tecnología.
- El hardware sin logotipo público (iWave, Teltonika, OnLogic, Iridium, Technoton) se dibuja con íconos de línea propios.
